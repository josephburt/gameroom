# GROK NES

A browser NES emulator. Play the built-in demo, or drop in a `.nes` ROM you legally own.

**Play it:** [https://josephburt.github.io/grok-nes/](https://josephburt.github.io/grok-nes/)

## Controls

| NES | Keyboard |
|---|---|
| D-Pad | Arrow keys or WASD |
| A | Z or J |
| B | X or K |
| Start | Enter |
| Select | Shift or Space |
| Pause | P |
| Reset | R |

Xbox / DualShock / generic pads work after you press a button on them.

## Hosting

This is a static site. GitHub Pages deploys from `main` via Actions. No server, database, or build step.
