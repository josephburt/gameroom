Google Drive setup

One-time Cloud project. Credentials stay in this browser. Authorized JavaScript origins must include:

  • https://gameroom.burtlabs.org
  • http://localhost:8765
  1. Create a Google Cloud project and enable Google Drive API + Google Picker API.
  2. OAuth consent screen: External, add yourself as a test user.
  3. Create an OAuth Web application client ID with those origins (required).
  4. API key and project number (App ID) help the picker download binary ROMs and zips.
